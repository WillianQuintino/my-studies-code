# 🛍️ Gerador de QR Codes para E-commerces com Node.js

Projeto desenvolvido como parte do bootcamp **MeuTudo - Mobile Developer** da [DIO.me](https://www.dio.me/). O objetivo é criar um gerador de QR Codes de forma simples e rápida via terminal, utilizando apenas Node.js.

Com este gerador, você poderá criar QR Codes personalizados para links de produtos de e-commerces, facilitando o acesso direto a páginas de vendas online.

## 🚀 Tecnologias Utilizadas

- [Node.js](https://nodejs.org/)
- [Inquirer](https://www.npmjs.com/package/inquirer) — para interação via terminal
- [qrcode](https://www.npmjs.com/package/qrcode) — para geração dos QR Codes

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/WillianQuintino/my-studies-code.git

# Acesse a pasta do projeto
cd my-studies-code/bootcamps/dio.me/meutudo---Mobile-Developer/03. Gerenciando Pacotes com Node.js com NPM/04. [Desafio de projeto] Criando um Gerador de QR Codes para E-commerces com Node.js/projeto-qrcode

# Instale as dependências
npm install
````

## ▶️ Como Usar

Após instalar as dependências, execute o seguinte comando no terminal:

```bash
npm start
```

## 🧠 Conceitos Praticados

* Criação de aplicações Node.js sem front-end
* Uso de bibliotecas de terceiros (qrcode e inquirer)
* Interação com o usuário via terminal
