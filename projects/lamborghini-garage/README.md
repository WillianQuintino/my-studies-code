# Lamborghini Garage 🚗

Aplicativo mobile desenvolvido em React Native + Expo + TypeScript para exibir uma garagem de carros Lamborghini, consumindo dados de uma API fake.

## 📱 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio da DIO para praticar o consumo de APIs em aplicativos React Native, organização de código e construção de componentes escaláveis.

O app exibe informações de diferentes modelos de Lamborghini, permitindo navegar entre eles e visualizar detalhes como nome, ano de lançamento e preço.

## 🚀 Como rodar o projeto

1. Clone este repositório:
   ```sh
   git clone https://github.com/seu-usuario/lamborghini-garage.git
   cd lamborghini-garage
   ```

2. Instale as dependências:
   ```sh
   npm install
   ```

3. Inicie o projeto:
   ```sh
   npm start
   ```
   Ou use os scripts para rodar em um emulador Android/iOS:
   ```sh
   npm run android
   npm run ios
   ```

## 🗂 Estrutura de Pastas

- `src/api/` – Funções para consumo da API.
- `src/components/` – Componentes reutilizáveis (CardView, BuyButton, Divider).
- `src/constants/` – Constantes globais (URLs da API e assets).
- `src/screens/` – Telas principais do app.
