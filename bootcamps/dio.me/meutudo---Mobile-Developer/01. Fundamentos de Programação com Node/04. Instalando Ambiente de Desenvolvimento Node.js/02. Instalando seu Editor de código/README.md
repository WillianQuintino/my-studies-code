- Ou busque no google baixar VSCode.
- Totalmente grátis

## Os painéis do seu vscode

- Na esquerda:
  - o Primeiro é o painel de navegação:
  - Pesquisa no codigo
  - Controle de git Github ele nao gosta muito de utilizar
  - Area de debugs
  - Area de exteções
  - Não tem nativo o Thunder client pata testar chamadas de APIs
  - Remote explorer também não nativo
- No centro temos o paínel de code tem varias arbas
- Na parte de baixo ao abrir ele tem o painel de terminal (ctrl + Shift + ')
