## 🎯 Objetivo do Trilha

Este grupo tem como foco principal o estudo e prática dos seguintes temas:

- [ ] Introdução ao Node.js
- [ ] Gerenciamento de Pacotes com NPM
- [ ] TypeScript para Node.js
- [ ] Criação de APIs RESTful
- [ ] Projeto prático final: API da Champions League

> ✅ Os conceitos serão marcados conforme o progresso.

## 🛠️ Tecnologias do Trilha

- **Linguagens:** JavaScript, TypeScript
- **Frameworks:** Node.js, Express
- **Ferramentas:** NPM, Git, Postman, VSCode

---

## 📝 Notas Pessoais

> Utilize esta seção para anotações rápidas sobre o trilha.

- `npx tsc --init` para iniciar TypeScript
- `nodemon` para reiniciar server automaticamente
- Instale dependências dev com `npm install -D`
- Use `Postman` para testar as rotas da API
