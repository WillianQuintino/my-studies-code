# 🛒 Shopee Cart - Desafio de Projeto DIO (Node.js)

Este é o repositório da implementação do desafio de projeto **"Carrinho de Compras da Shopee com Node.js"**, proposto pela [DIO (Digital Innovation One)](https://www.dio.me/). O objetivo é simular as operações básicas de um carrinho de compras utilizando JavaScript com Node.js, reforçando conceitos como manipulação de arrays, orientação a objetos e boas práticas de desenvolvimento backend.

## 📁 Estrutura do Projeto

```
.
├── index.js              # Arquivo principal de execução
├── Product.js            # Classe que representa um produto
├── Cart.js               # Classe que gerencia o carrinho de compras
└── README.md             # Documentação do projeto
```

## 🚀 Funcionalidades

* Adicionar produtos ao carrinho
* Remover produtos
* Calcular valor total
* Exibir resumo do carrinho

## 🧠 Conceitos Trabalhados

* Modularização com Node.js
* Classes e orientação a objetos
* Manipulação de listas (arrays)
* Lógica de programação para simulação de um sistema real

## 💡 Exemplo de Uso

```bash
node index.js
```

O terminal exibirá as operações realizadas no carrinho:

```bash
Produto adicionado: Celular - R$ 2500.00
Produto adicionado: Fone de Ouvido - R$ 250.00
Total do carrinho: R$ 2750.00
Produto removido: Fone de Ouvido
Total do carrinho: R$ 2500.00
```

## 📚 Pré-requisitos

* Node.js instalado na máquina (versão 14+ recomendada)
