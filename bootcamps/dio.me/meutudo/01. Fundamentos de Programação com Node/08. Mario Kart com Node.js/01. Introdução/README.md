# Introdução

## Desafio de projeto do Felipão: Mario Kart.JS

**Objetivo:**

Mario Kart é uma série de corrida desenvolvida e publicada pela Nintendo. Nosso desafil será criar uma lógica de um jogo de vídeo game para simular corridas de Mario Kart, levando em considerção as regras e mecânicas abaixo.
