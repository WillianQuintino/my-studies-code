# Portfólio Mobile - DIO 🚀
 
Aplicativo mobile desenvolvido em React Native + TypeScript como desafio prático da DIO. O objetivo é criar um portfólio simples com duas telas: uma de perfil e outra de habilidades, utilizando navegação, componentes e estilização.
 
## 📱 Sobre o Projeto
 
Este projeto foi criado para demonstrar conhecimentos em React Native, navegação entre telas, criação de componentes reutilizáveis e estilização. O app possui:
 
- **Main Screen:** Exibe uma foto, nome e links importantes (LinkedIn, GitHub, Email).
- **Skill Screen:** Exibe novamente a foto e nome, além de uma lista de habilidades e o nível de cada uma.
 
## 🚀 Como rodar o projeto
 
1. Clone este repositório:
   ```sh
   git clone https://github.com/seu-usuario/portfolio-mobile-dio.git
   cd portfolio-mobile-dio
   ```
 
2. Instale as dependências:
   ```sh
   npm install
   ```
 
3. Execute o projeto:
   ```sh
   npm start
   ```
   Ou rode em um emulador:
   ```sh
   npm run android
   npm run ios
   ```
 
## 🗂 Estrutura de Pastas
 
- `src/screens/` – Telas principais do app (MainScreen, SkillScreen)
- `src/components/` – Componentes reutilizáveis (SocialLink, SkillItem)
- `assets/` – Imagens do projeto
