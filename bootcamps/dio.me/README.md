# 📚 Repositório de Bootcamps - DIO.me

Este repositório contém os materiais, anotações e projetos realizados durante os bootcamps oferecidos pela [DIO.me](https://www.dio.me), organizados de forma hierárquica para facilitar a navegação e o acompanhamento do progresso.

## 📁 Estrutura do Repositório
A organização segue o seguinte padrão:

/📦Nome-do-Bootcamp
┣ 📂Grupo
┃ ┣ 📂Módulo
┃ ┃ ┣ 📂Aula
┃ ┃ ┗ 📄...
┗ 📄README.md

### 🔍 Explicando a Estrutura:

- **Nome-do-Bootcamp/**: Pasta principal de cada bootcamp. O nome deve ser idêntico ou semelhante ao título oficial do bootcamp.
- **Grupo/**: Refere-se a uma divisão lógica de trilhas ou especializações dentro do bootcamp (ex: *Frontend*, *Backend*, *Banco de Dados*).
- **Módulo/**: Cada módulo representa uma etapa de aprendizado dentro do grupo (ex: *Introdução ao JavaScript*, *Spring Boot Avançado*).
- **Aula/**: Conteúdo individual com código-fonte, anotações e exemplos práticos de cada aula.
